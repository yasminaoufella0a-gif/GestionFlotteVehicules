# Gestion de Flotte de Véhicules

## Description
Ce projet est une application Java permettant de gérer une flotte de véhicules.

## Fonctionnalités
- Gestion des voitures, motos et camions
- Lecture des données depuis un fichier CSV
- Location et retour des véhicules
- Calcul du tarif de location
- Gestion des exceptions personnalisées
- Calcul des statistiques
- Génération d'un rapport texte

## Technologies utilisées
- Java
- IntelliJ IDEA
- Git
- GitHub

## Concepts de programmation
- Héritage
- Classe abstraite
- Interfaces
- Polymorphisme
- Exceptions personnalisées
- ArrayList
- Lecture de fichiers CSV
